# TabbyML

**Software is cheap to build. Making it better is the hard part.**

Agents make the gap obvious. The first version takes a weekend; every version after it is a guess about what "better" means. We uncover failure patterns across your agent's runs and turn them into eval cases and graders that guide improvement.

## How it works

1. **Define** — Patterns in your runs become eval cases and graders you approve.
2. **Climb** — Changes are proposed and tested 24/7; measurement decides what stays.

The output is a measurably better agent each cycle — and a quality bar the team can keep raising.
